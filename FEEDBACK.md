# FEEDBACK.md — Your review inbox

How to use: look at the site, write notes below in this format, then tell Codex: **"Apply FEEDBACK.md."** That's the only prompt you need for every review round.

Format: `- [where] what's wrong → what you want (priority: high/med/low)`

Example:
- [Home / hero] name feels small and safe → make it fill the width, more confident (high)
- [Projects] spec rows too cramped on mobile → more breathing room, stack labels on top (med)
- [Global] accent orange used too often → only on links + the signature line (high)

If you can't say why something feels off, write the feeling: "feels template-y", "too busy", "too empty", "feels cheap". Codex will diagnose it.
